# אפליקציית אנדרואיד - התראות צוות עוגן פליי

אפליקציה פנימית לצוות פיקוח וניהול בלבד - סורקת כל 30 שניות ומתריעה (התראת מכשיר) על
אפליקציות/דיווחים/הודעות/בקשות חדשות שממתינות לטיפול.

## איך בונים ומריצים

1. פותחים את Android Studio
2. "Open" -> בוחרים את התיקייה `android-app` הזו (לא את `ogen-play` כולה - רק את
   `android-app`)
3. ממתינים ל-Gradle Sync (בפעם הראשונה זה יכול לקחת כמה דקות - מוריד תלויות)
4. מחברים טלפון אנדרואיד (עם "ניפוי באגים דרך USB" מופעל) או פותחים אמולטור, ולוחצים Run ▶
5. באפליקציה: מתחברים עם אותם פרטי ההתחברות של האתר (רק חשבון מנהל או צוות פיקוח יתקבל),
   ואז לוחצים "התחלת ניטור"

## למה יש התראה קבועה כל עוד הניטור פעיל

זו לא בחירה שלנו - זו דרישה של אנדרואיד עצמו (מ-Android 8 ואילך): כל אפליקציה שרוצה להריץ
קוד ברקע בלי הגבלת זמן (Foreground Service) חייבת להציג התראה קבועה וגלויה, כדי שהמשתמש
תמיד ידע שמשהו רץ. זו הדרך היחידה לקבל סריקה אמיתית כל 30 שניות (בלי זה, אנדרואיד עצמו
עוצר אפליקציות ברקע אחרי דקות ספורות).

## בניית APK להתקנה על כמה מכשירים

Build -> Build Bundle(s) / APK(s) -> Build APK(s). הקובץ ייווצר בתוך
`app/build/outputs/apk/debug/app-debug.apk` - אפשר להעביר אותו (למשל בוואטסאפ/מייל) לכל
מכשיר אנדרואיד של חבר צוות אחר, ולהתקין (צריך לאשר "התקנה ממקורות לא ידועים" במכשיר).
